# Calculator wording

Write for someone setting up an attack at the table. Give them the next step,
using the names they see on the controls. Keep actual rule names unchanged.

- Use ordinary words: stats, weapons, squad, wounds, saves.
- Say what a control does. Avoid slogans and filler around results.
- Keep instructions close to the control they explain.
- Show applied bonuses beside the squad. Put longer lists of omitted rules
  under **Rules not included**, and keep them in downloaded results.
- Keep source dates, missing stats and unsupported rules visible. Shorter copy
  must not imply that the data or calculation is more complete than it is.
- Use contractions where they read naturally. Don't add deliberate typos,
  fake testimonials or invented personal experience to sound human.

Examples from this edit:

| Before | After |
| --- | --- |
| Calculate an explicitly restricted baseline | Use basic defences only |
| Basic weapon package (no optional upgrades) | Standard weapons (no upgrades) |
| Your next roll, with perspective. | Results |
| Choose individual weapons below | Choose weapons yourself |

References: [NN/g's study of AI writing in products](https://www.nngroup.com/articles/genai-write-for-the-web/)
and [GOV.UK's interface writing guidance](https://www.gov.uk/service-manual/design/writing-for-user-interfaces).
These support concise, clear interface copy; they are not tests of who wrote it.
